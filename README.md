# **MAji**  
🎲 **MAji** 是一个面向网络麻将游戏 **雀魂**（Mahjong Soul）的实验性 AI 项目，旨在通过机器学习和强化学习分析对局数据，推理局内信息和策略，帮助玩家提升对局胜率。

![Version](https://img.shields.io/badge/version-0.1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

---

## **功能特点**  
- 🀄 **对局图像识别**：通过图像识别提取详细的对局数据（CNN网络），包括玩家手牌、牌河和场上状态。
- 🔮 **对手手牌预测**：基于图像识别获得的信息，推测其余三位玩家可能的手牌分布（LSTM网络）。
- 🤖 **强化学习推理**：结合手牌的预测结果，通过强化学习实时提供出牌建议，帮助玩家优化策略。

## **开发计划**
原本这是我在学校上完机器学习课程之后自己练手的项目，当时沉迷打雀魂（四麻雀杰二三的水平），数据集都是我在金之间收集的自己的对局。
后来开发遇到瓶颈，一个人开发不动了，而且雀魂也退坑了，懒得收集新的数据集了，现在想起来更新个详细点的README，等待有缘人。🐢
- **阶段 1: 图像识别（已完成 ✅）**
  - 获取并解析对局截图中的所有玩家数据。
  - 数据集来自约100张金之间的对局截图，总计约10000张麻将牌的图像（不过有部分重复的情况，因为后续的手牌预测需要所以保留了同一场对局的几张不同巡目的截图）。
  - 识别准确率有待提升，我认为主要是受限于数据集太小。

- **阶段 2: 手牌预测（开发中 🚧）**
  - 构建手牌预测模型，推断其他玩家的可能手牌分布。
  - 数据集来自约100张金之间的对局截图，包含共64场对局的6巡、12巡和18巡（巡目不足的向上取整）的截图。
  - 推理准确率遇到瓶颈（目前卡住的地方 ⚠️），不确定是模型结构问题还是数据集太小的问题。

- **阶段 3: 强化学习（待开发 🚧）**
  - 基于预测结果，生成个性化出牌建议。
  - 网上应该有很多麻将AI都是用的强化学习，这部分我没有报什么特别的期待。

- **未来功能**：
  - 增加实时游戏数据捕获支持（预计是使用python实时截图）。
  - 提供对局回顾与策略可视化功能（这是AI生成的，可不是我说的）。
